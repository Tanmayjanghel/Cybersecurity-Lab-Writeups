# Cybersecurity-Lab-Writeups
Cybersecurity lab write-ups | TryHackMe, HTB, PortSwigger &amp; OverTheWire | Pentesting, exploitation, enumeration &amp; privilege escalation.


A collection of cybersecurity lab write-ups, walkthroughs, and technical notes from TryHackMe, Hack The Box, OverTheWire, and PortSwigger. Documenting hands-on learning in penetration testing, ethical hacking, Linux and Windows enumeration, web application security, exploitation, and privilege escalation. Focused on methodology, practical commands, vulnerability analysis, and continuous improvement in cybersecurity.
